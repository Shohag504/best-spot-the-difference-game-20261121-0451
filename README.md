Dhaka Days — an original spot-the-difference game: three hand-drawn scenes (Rickshaw Street, Night Bazaar, River Sunset) with 5 to 8 hidden differences each, a countdown timer, hints, score and levels. Every picture is drawn in code on canvas, so the game runs fully offline in any desktop browser from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play with mouse and keyboard (H for a hint, M to mute, R to restart a level).
